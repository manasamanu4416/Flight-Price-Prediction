# Flight Price Prediction 

A Machine Learning project that predicts flight ticket prices using Python, Pandas, Scikit-learn with a React.js frontend.

### Features
- Predicts flight prices based on airline, source, destination, date, stops
- Python Flask backend with ML model (Random Forest)
- React.js + Vite frontend for user input
- Model trained on Flight Dataset

### Tech Stack
- **Backend:** Python, Flask, Scikit-learn, Pandas, NumPy
- **Frontend:** React.js, Vite, Tailwind CSS

### How to Run
1. Backend: `cd backend` -> `pip install -r requirements.txt` -> `python app.py`
2. Frontend: `cd frontend` -> `npm install` -> `npm run dev`

### Note
Model file `model.pkl` (130MB) is not uploaded due to GitHub size limit. Train the model using `Flight_Price_Prediction.ipynb` to generate it.
